Bundled third-party scripts used by the commission report to export a PDF (includes/reports/expenses_summary.php).
They used to be loaded from cdnjs.cloudflare.com; they are kept here so the admin makes no request to an outside server.

jspdf.umd.min.js              jsPDF 2.5.1 (MIT) https://github.com/parallax/jsPDF
jspdf.plugin.autotable.min.js jsPDF-AutoTable 3.5.25 (MIT) https://github.com/simonbengtsson/jsPDF-AutoTable

Both files are the unmodified builds published by cdnjs (their SHA-512 matches the SRI hash cdnjs lists).
